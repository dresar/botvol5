# Services Directory

Folder ini berisi layanan-layanan yang digunakan aplikasi WhatsApp Bot.

## Layanan

- APIManager: Mengelola permintaan API dan caching
- UtilityManager: Menyediakan fungsi-fungsi utilitas seperti QR code, URL shortener, dll.
- Monitoring: Memantau kinerja sistem dan penggunaan sumber daya
- Optimizer: Mengoptimalkan penggunaan sumber daya sistem
