# Source Code Directory

Folder ini berisi kode sumber utama aplikasi WhatsApp Bot.

## Struktur Folder

- `core/`: Berisi komponen inti aplikasi
- `services/`: Berisi layanan-layanan yang digunakan aplikasi
- `utils/`: Berisi fungsi-fungsi utilitas
- `handlers/`: Berisi handler untuk berbagai jenis pesan dan perintah
- `models/`: Berisi model data dan skema database
