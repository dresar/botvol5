# Handlers Directory

Folder ini berisi handler untuk berbagai jenis pesan dan perintah.

## Handler

- Command Handler: Menangani perintah dari pengguna
- Message Handler: Menangani pesan masuk
- Group Handler: Menangani event grup (join, leave, dll)
- Game Handler: Menangani perintah permainan
- Admin Handler: Menangani perintah admin
