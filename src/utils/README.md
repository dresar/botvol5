# Utils Directory

Folder ini berisi fungsi-fungsi utilitas yang digunakan di seluruh aplikasi.

## Utilitas

- Text Processing: Fungsi untuk memproses teks
- Rate Limiting: Fungsi untuk membatasi penggunaan fitur
- Sentiment Analysis: Fungsi untuk analisis sentimen
- QR Code Generator: Fungsi untuk menghasilkan QR code
- URL Shortener: Fungsi untuk memperpendek URL
- Calculator: Fungsi kalkulator sederhana
